# This file provides instructions for reviewing documentation and ensuring it follows our editorial, language, and brand guidelines.
# Edit this file to update the guidance for all contributors. 

When generating, reviewing, or correcting any content, markdown file, or documentation in the documentation folder, always follow these guidelines:

**LNDS Editorial Style:**
- Use clear, neutral, device-agnostic language.
- Prefer active voice; use passive only if the actor is unknown or irrelevant.
- Use UK English spelling and grammar.
- Use “Select” (not “Click”), “Enter” (not “Type”), and “They” (not “he/she”).
- For navigation, use “Go to” and “Open” appropriately.
- Do not number headings; use sentence case for all headings.
- Structure headings logically (H1 once, then H2, H3, etc.).
- Use serial (Oxford) commas in lists.
- Avoid contractions in critical instructions.
- Use double quotes for literal values, single quotes for quotes within quotes.
- Use hyphens, en dashes, and em dashes correctly.
- Use colons and semicolons as per style guide.
- Format lists and tables with clear labels and summaries.
- Ensure accessibility: provide descriptive alt text, avoid deep navigation, use descriptive links, and avoid directional language.
- When bolding labels in documentation lists (e.g., **Documented:**), always include the colon in bold (e.g., **Documented:** not **Documented**:). This ensures the colon is visually part of the label.

**LNDS Brand Colors and Visuals:**
- Use the LNDS color palette for diagrams and visuals:
  - Red: #E51F26, Blue: #4EAEDC, Medium Grey: #B5BFC4, Light Grey: #D2D9DB, Dark Grey: #414547
  - Complementary: Purple: #70559F, Dark Blue: #24388C, Teal/Green: #6EC0A7, Yellow: #F5C945
- For Mermaid diagrams, use the specified color and border styles.
- Keep diagrams and screenshots simple, consistent, and accessible.
- Remove PII and decorative elements from screenshots.

**Overall Language and Tone:**
- Use a business but human (conversational) tone.
- For any situation not covered above, priortize applying the Microsoft Style Guide and its tone of voice, language, and writing style.

Always align with the LNDS Editorial Style Guide and Brand Colors reference.
